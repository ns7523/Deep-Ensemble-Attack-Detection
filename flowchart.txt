Extension
----------

In the base paper the author mentioned to use different Dataset for analysis with Deep learning models like DNN, LSTM got 98% of accuracy,
As an extension we applied an ensemble method  combining the predictions of multiple individual models to produce a more robust and accurate final prediction.
However, we can further enhance the performance by exploring other ensemble techniques such as CNN and CNN + LSTM got 99% of accuracy, for KDDCup, NSL Dataset,
As an extension we can build the front end using the flask framework for user testing and with user authentication.
